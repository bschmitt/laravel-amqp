Laravel AMQP
It's simple!

It's easy to work with RabbitMQ message queues

📦

Simple Publish & Consume

Clean, intuitive API for publishing and consuming messages with full AMQP property support — priority, TTL, correlation IDs, and custom headers out of the box.

⚡

Laravel Queue Driver

Set QUEUE_CONNECTION=amqp and use dispatch() / queue:work as usual — RabbitMQ handles persistence, delays, and failures behind the scenes.

🛠️

Artisan Commands

Long-running workers and CLI tooling via amqp:work, amqp:consume, amqp:listen, amqp:publish, and amqp:purge.

🔄

RPC Pattern

Built-in request/response with rpc() and reply(), including automatic correlation ID handling and reply-queue management.

🔁

Retry & Dead-Letter Pipeline

Declarative RetryPolicy + DeadLetterTopology + RetryHandler with fixed/exponential backoff, automatic DLQ routing, and one-flag CLI integration (--retry --declare-topology).

⏱️

Delayed Messaging

Schedule deliveries with publishLater() or amqp:publish --delay-ms. Works on stock RabbitMQ (TTL+DLX) or the delayed-message exchange plugin. Includes PublishBackoff for transient publisher errors.

📐

Typed Messages & Schema

Plain-PHP DTOs via TypedMessage, published with publishTyped() / consumed with consumeTyped(). Optional zero-dependency JSON-Schema-lite validation on both directions.

🚀

Production Infrastructure

ExchangeTopology builders, QueueProfile quorum/priority presets, resilient reconnect + ConnectionPool, W3C trace propagation, correlation IDs, and ConsumerLifecycle hooks.

🧪

SAGA, Events & Testing

Saga step/compensation workflows, Laravel publish/consume events, consume middleware pipeline, AsyncPublisher with confirms, and Amqp::fake() with Laravel-style assertions.
